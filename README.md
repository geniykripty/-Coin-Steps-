## О проекте

Coin Steps Bot — это автоматизированный торговый бот, который зарабатывает на колебаниях цены криптовалют. Он выставляет лесенку заявок на покупку: каждая следующая ниже предыдущей. Когда цена опускается и задевает заявку, монета покупается. Когда цена поднимается, бот продаёт её дороже и забирает разницу.

Работает с любыми парами из файла `tokens.txt` (по умолчанию BTC/USDT и ETH/USDT). Управляется из обычного браузера.

## Ключевые возможности

| Возможность | Описание |
|---|---|
| Сетка покупок | До 60 уровней заявок, настраиваемый шаг и диапазон |
| Автопродажа с прибылью | Тейк-профит настраивается от 2% до любого значения |
| Повтор по кругу | После продажи бот снова ставит покупку на том же уровне |
| Понятная статистика | Реализованная и нереализованная прибыль, история сделок |
| Звуки и уведомления | Каждое событие сопровождается звуком и всплывающим сообщением |
| Сохранение состояния | Ордера лежат на бирже, после перезапуска бот продолжает с того же места |
| График с ордерами | Свечной график с наложением заявок в реальном времени |
| Бэктест сетки | Проверка стратегии на исторических данных перед запуском |
| Экспорт в Excel | Выгрузка любой таблицы в xlsx одним кликом |
| Безопасность | API-ключ без права вывода, привязка к IP, встроенные защиты |
