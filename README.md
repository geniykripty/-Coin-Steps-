## О проекте

Coin Steps Bot — это автоматизированный торговый бот, который зарабатывает на колебаниях цены криптовалют. Он выставляет лесенку заявок на покупку: каждая следующая ниже предыдущей. Когда цена опускается и задевает заявку, монета покупается. Когда цена поднимается, бот продаёт её дороже и забирает разницу.

Работает с любыми парами из файла tokens.txt (по умолчанию BTC/USDT и ETH/USDT). Управляется из обычного браузера.

📘 Подробная документация: [справка](https://geniykripty.github.io/-Coin-Steps-/help.html) — установка, настройка, примеры, решение проблем.

## Ключевые возможности

| Возможность | Описание |

| График с ордерами | Свечной график с наложением заявок в реальном времени |
| Бэктест сетки | Проверка стратегии на исторических данных перед запуском |
| Экспорт в Excel | Выгрузка любой таблицы в xlsx одним кликом |
| Безопасность | API-ключ без права вывода, привязка к IP, встроенные защиты |

## Как это работает

Цена опускается → Покупка исполняется → Бот ставит продажу по TP
      ↑                                              ↓
      └────────── Продажа исполнилась ←──────────────┘
                   (бот ставит новую покупку)

Чем больше колебаний цены, тем больше прибыли. Лучше всего работает на боковом рынке, когда цена гуляет в коридоре.

## Быстрый старт

1. Установи Python 3.10+ с галочкой "Add Python to PATH".
2. Получи API-ключи MEXC (права: Spot Reading, Spot Trading, Account Reading. Право Withdraw включать нельзя).
3. Настрой файл .env, вписав свои ключи.
4. Запусти бота (двойной клик по start.bat на Windows).
5. Открой интерфейс в браузере: http://localhost:8000

📘 Нужна помощь? Открой [справку](https://geniykripty.github.io/-Coin-Steps-/help.html) — там пошаговые инструкции.

## Безопасность

- API-ключ без права вывода средств.
- Привязка ключа к IP-адресу (рекомендуется).
- Окна подтверждения перед важными действиями.
- Защита от двойного клика и опечаток в цене.

Важно: никогда не публикуй файл .env и не включай право Withdraw на API-ключе.

## Частые вопросы

**Что будет, если выключить компьютер?**  
Ордера останутся на бирже и исполнятся. Бот продолжит работу после перезапуска.

**Сколько нужно денег для старта?**  
Минимум 5–10 USDT для пробы. Сумма ордера от 1.05 USDT.

**Бот торгует фьючерсами?**  
Нет, только спот. Без кредитного плеча.

## Важное предупреждение

Торговля криптовалютой связана с риском. Прошлые результаты не гарантируют будущую прибыль. Используй только те средства, которыми готов рискнуть.
