🕸️ Что это за бот

Коротко и без сложных слов

🕸️

Сетка из покупок

Ты задаёшь стартовую цену, шаг и сумму. Бот выставляет на бирже «лесенку» заявок на покупку: каждая следующая — ниже предыдущей. За один раз — до 60 уровней.

💰

Продажа с прибылью

Как только покупка исполнилась, бот сам ставит продажу чуть дороже — на столько процентов, сколько ты указал в поле «Тейк-профит».

🔄

Повтор по кругу

После продажи бот снова ставит покупку на том же уровне. Пока цена ходит вверх-вниз, каждый уровень зарабатывает снова и снова.

📊

Понятная статистика

Сколько куплено и продано, сколько заработано, какая прибыль «на бумаге» по ещё не проданным монетам, средняя цена покупки, история всех ордеров.

🔔

Звуки и сообщения

Покупка, продажа, выставление ордера, отмена и ошибки сопровождаются своим звуком и всплывающим сообщением — можно не смотреть в экран.

💾

Помнит, что делал

Бот записывает свои ордера в файл Data/autosell.json. Ордера лежат на бирже, поэтому после выключения света или перезапуска бот продолжает с того же места.

💡
Как бот зарабатывает — простыми словами
Цена монеты почти никогда не идёт в одну сторону: она качается вверх и вниз. Бот ставит заявки на покупку на нескольких ценах ниже текущей. Когда цена опускается и «задевает» заявку — монета покупается. Когда цена немного поднимается — бот продаёт её дороже, чем купил, и забирает разницу. Чем больше таких качаний, тем больше прибыли. Лучше всего это работает на «боковом» рынке, когда цена гуляет в коридоре.
⚠️
Главный риск
Если цена долго падает и не возвращается, ты накопишь монеты по всё более низким ценам и будешь ждать отскока. Убыток фиксируется только когда ты сам продашь монеты ниже цены покупки, но деньги при этом «заморожены» в монете. Прибыль не гарантирована — вкладывай только те средства, которыми готов рискнуть.
Чего бот не делает
  • Не выводит деньги с биржи и не может этого сделать (у ключа не должно быть права на вывод).
  • Не торгует фьючерсами и не использует кредитное плечо — только обычный спот.
  • Не трогает ордера, которые он не выставлял сам.
  • Не предсказывает цену и не обещает прибыль.

🐍 Установка Python

Пошаговая инструкция для новичков — займёт 5–10 минут

ℹ️
Зачем нужен Python?
Бот — это программа на языке Python. Чтобы она запустилась на твоём компьютере, нужно один раз установить Python версии 3.10 или новее. Если Python уже стоит (проверка — в шаге 3), этот раздел можно пропустить.
Шаг 1 — Скачай Python

Открой официальный сайт и скачай последнюю стабильную версию (подойдёт Python 3.11 или 3.12). Версии «beta» и «release candidate» не бери.

https://www.python.org/downloads/
Шаг 2 — Запусти установщик
  • ВАЖНО: в самом низу первого окна поставь галочку "Add Python to PATH"
  • Нажми "Install Now"
  • Дождись окончания установки (2–3 минуты)
  • Нажми "Close"
⚠️
Без галочки PATH бот не запустится
Эта галочка позволяет Windows найти Python из любой папки. Если забыл её поставить — удали Python и установи заново.
Шаг 3 — Проверь установку

Нажми Win + R, введи cmd, нажми Enter. В чёрном окне выполни:

python --version REM если "python" не найден, попробуй так: py --version

Должно появиться что-то вроде Python 3.12.4.

🔴
Если Python не найден
1. Перезагрузи компьютер.
2. Попробуй команду py --version вместо python --version.
3. Если не помогло — переустанови Python и не забудь про галочку PATH.
Шаг 4 — Проверь pip

pip — это установщик библиотек, он ставится вместе с Python:

pip --version

Если видишь версию — всё готово. Если нет, выполни: python -m ensurepip --upgrade

🎉
Готово!
Теперь можно переходить к ключам биржи.

🔑 API-ключи MEXC

Как дать боту доступ к бирже — безопасно и без права вывода денег

2
Ключа нужно получить: API Key и Secret Key
90
Дней — стандартный срок жизни ключа
3
Права нужно включить (вывод — нельзя)
Как получить ключ на MEXC
1

Войди в аккаунт

Открой mexc.com и авторизуйся. Пройди верификацию (KYC), если ещё не проходил — без неё API не работает.

2

Открой раздел API

Профиль → Open API или сразу mexc.com/user/openapi.

3

Создай ключ

Нажми "Создать API", придумай название (например, "CoinStepsBot"), подтверди через 2FA и email.

4

Скопируй оба ключа

Сразу сохрани API Key и Secret Key. Secret показывается только один раз — потом его не восстановить, придётся создавать новый ключ.

Какие права включить

Включай только то, что нужно боту, и ничего лишнего:

✓ Spot Reading (чтение)
✓ Spot Trading (торговля)
✓ Account Reading (баланс)
✗ Withdraw (вывод) — НЕ включать
✗ Futures — не нужно
✗ Universal Transfer — не нужно
⚠️
Привяжи ключ к своему IP-адресу
В настройках ключа есть «белый список IP». Если добавить туда IP своего компьютера, ключ будет работать только с него — даже украденный ключ окажется бесполезным. Побочный эффект приятный: MEXC считает такой ключ бессрочным, и бот покажет «Ключ: Бессрочный (IP)». Если у тебя динамический IP и он часто меняется — можно оставить поле пустым, но это менее безопасно.
Файл .env — куда вписать ключи

В папке с ботом лежит файл .env. Открой его в Блокноте и впиши свои значения:

# Ключи с mexc.com → Open API MEXC_API_KEY=твой_api_key MEXC_SECRET_KEY=твой_secret_key # Тип рынка — для этого бота всегда spot MARKET_TYPE=spot # Запасной вариант учёта срока ключа (см. ниже). Дата и время создания ключа из личного кабинета биржи. API_KEY_CREATED="2026-08-18 17:29:29" API_KEY_DAYS=90
🔒
Файл .env — секретный
Никому не показывай его, не отправляй в чаты и не выкладывай в интернет (GitHub и т. п.). Кто знает Secret Key — тот может торговать на твоём аккаунте. Если ключ попал на чужие глаза — сразу удали его в MEXC и создай новый.

После любого изменения .env перезапусти бота: файл читается только при старте.

Как бот следит за сроком ключа

Бот сам спрашивает у MEXC, сколько ещё проживёт ключ и привязан ли он к IP (раз в 5 минут). Остаток показывается в блоке «Управление ботом MEXC». Строки API_KEY_CREATED и API_KEY_DAYS нужны только как запасной вариант — на случай, если биржа не ответила (например, у ключа нет права «Account Reading»).

ЦветОстатокЧто делать
🟢 Зелёныйбольше 14 днейНичего.
🟡 Жёлтыйот 6 до 14 днейПора готовить новый ключ.
🔴 Красный5 дней и меньшеСрочно продли ключ или создай новый.

Если ключ уже истёк, бот сообщит об этом красным сообщением.

Продление: за 5 дней до истечения срока действия вашего API-ключа вы можете продлить его действие на 90 дней в разделе Мой ключ API — Действие — Продлить.

🔁
Как заменить ключ, когда он истёк
1. На mexc.com/user/openapi удали старый ключ и создай новый с теми же правами.
2. Впиши новые MEXC_API_KEY и MEXC_SECRET_KEY в .env.
3. Обнови API_KEY_CREATED — дата и время создания нового ключа.
4. Перезапусти бота.
Ордера, которые бот уже выставил, останутся на бирже — после перезапуска бот продолжит их отслеживать.

🚀 Запуск бота

Три шага: ключи → запуск → открыть в браузере

Шаг 1 — Заполни .env

Впиши ключи, как описано в разделе «API-ключи MEXC».

Шаг 2 — Запусти сервер

🪟 Windows (самый простой способ). Создай в папке с ботом текстовый файл, вставь в него код ниже и сохрани как start.bat:

@echo off chcp 65001 >nul cd /d "%~dp0" title Coin Steps Bot REM Ищем Python where py >nul 2>nul if %errorlevel%==0 ( set PYTHON=py ) else ( set PYTHON=python ) REM Создаём виртуальное окружение (отдельную папку для библиотек бота) if not exist venv ( %PYTHON% -m venv venv ) call venv\Scripts\activate.bat REM При первом запуске ставим нужные библиотеки python -c "import fastapi, ccxt, uvicorn, dotenv, slowapi" >nul 2>nul if errorlevel 1 ( echo Первый запуск - устанавливаю библиотеки... python -m pip install --quiet fastapi "uvicorn[standard]" ccxt python-dotenv slowapi ) REM Запускаем сервер python -m uvicorn main:app --host 127.0.0.1 --port 8000 pause
✅
Что делает этот файл
При первом запуске он сам создаст отдельную папку для библиотек и установит всё нужное (это займёт пару минут), потом запустит бота. Окно не закрывается при ошибке — ты успеешь прочитать сообщение. В дальнейшем бот запускается двойным кликом по start.bat.

🐧 Linux / Mac. В терминале, в папке с ботом:

# Один раз: установить библиотеки pip install fastapi "uvicorn[standard]" ccxt python-dotenv slowapi # Запустить сервер python -m uvicorn main:app --host 127.0.0.1 --port 8000
⚠️
Не закрывай окно с ботом
Чёрное окно — это и есть работающий бот. Закроешь окно — бот остановится (ордера на бирже при этом останутся). Параметр 127.0.0.1 означает, что бот доступен только с твоего компьютера — так безопаснее всего.
Шаг 3 — Открой интерфейс

Введи в адресную строку браузера:

http://localhost:8000
✅
Как понять, что всё в порядке
В блоке «Управление ботом MEXC» горит зелёный индикатор «Подключено: Спот» и показан срок действия ключа. Если индикатор красный — проверь ключи в .env и раздел «Частые вопросы и проблемы».

🪙 Список монет (tokens.txt)

Какими монетами торгует бот — одна строка на монету, перезапуск не нужен

ℹ️
Один файл для всех страниц
Из tokens.txt берётся переключатель монет на главной странице, на графике, в статистике и в бэктесте. Добавил монету в файл — кнопка с ней появится везде.
Как написать файл

Положи файл рядом с main.py (можно и в папку Data/) и впиши монеты:

# Монеты, с которыми работает бот BTC ETH SOL, XRP, DOGE # можно несколько в одной строке через запятую PEPE/USDT # пару можно писать целиком
ПравилоКак понимает бот
Записать монетуПо одной в строке или через запятую. Регистр и пробелы не важны: sol и SOL — одно и то же.
КомментарииВсё после # бот игнорирует. Пустые строки тоже.
Без парыSOL — это SOL/USDT. Если нужна другая пара, пиши её целиком: ETH/BTC.
Ошибки в строкеДопустимы только латинские буквы и цифры. Неверные записи молча пропускаются, повторы убираются.
Файла нет или он пустСервер сам отдаёт запасной список TRACKED_SYMBOLS из .env (по умолчанию BTC/USDT и ETH/USDT). Страницы получают его как обычный список, поэтому ошибок в чёрном окне нет.
Когда изменения вступают в силу
  • Сервер замечает изменение файла сам, а страницы бота проверяют его раз в 30 секунд. Ни перезапуск бота, ни F5 не нужны.
  • Монеты, которых нет на бирже MEXC (спот), на главной странице не показываются: проверь написание тикера.
  • Цены для графика берутся с Binance. Монеты, которых нет на Binance, на странице графика пропускаются; бэктест сетки тоже считается по ценам Binance, поэтому для редкой монеты расчёт может не получиться.
  • Выбранная монета запоминается. Если убрать её из файла, страница сама переключится на первую монету из списка.
  • Бот хранит выставленные ордера в Data/autosell.json и следит за ними независимо от файла. Если убрать монету из списка, ордера по ней не пропадут и продолжат отслеживаться, но управлять ими из интерфейса получится, только когда вернёшь монету в файл.
⚠️
Не убирай монету, пока по ней есть открытые ордера
Бот их не отменит, но ты перестанешь видеть их на экране. Сначала нажми «Отменить все ордера» по этой монете или закрой позиции, а потом убирай её из списка.

🖥️ Знакомство с экраном

Что где находится — сверху вниз

ℹ️
Сначала расчёт, потом биржа
Всё, что ты вводишь в «Параметры сетки», только считается на экране. На биржу ничего не уходит, пока ты не нажмёшь «Выставить сетку на биржу» и не подтвердишь действие. Поэтому можно спокойно экспериментировать с числами.
Блок на экранеЧто в нём
Шапка страницыСправа — плашка «Заработано»: реализованная прибыль по всем монетам за всё время работы бота (рядом написано, за сколько дней) и в процентах. Наведи курсор — появится разбивка «По активам». Если итог отрицательный, плашка становится оранжевой.
Верхняя панельПереключатель актива — все монеты из tokens.txt (с текущей ценой), кнопка «⬇ Бэктест сетки», кнопка «Справка» (эта страница).
Быстрые настройкиТри готовых набора «шаг / диапазон»: Консервативный, Сбалансированный, Агрессивный. Один клик — и поля заполнены.
Параметры сеткиПоля, которые ты задаёшь: Стартовая цена (с кнопкой «⟳ live»), Шаг %, Сумма ордера $, Диапазон %, Тейк-профит %.
Статистика сеткиРасчёт «что получится»: сколько будет ордеров, сколько всего USDT нужно, средняя цена входа, сколько монет купится, какой профит с одного цикла.
Уровни лимитных ордеровТаблица всех уровней: номер, просадка, цена, сколько монет, сумма в $, цена продажи (TP). Есть выгрузка в Excel.
БалансыСколько на аккаунте USDT и выбранной монеты (и её стоимость в USDT), свободно и в ордерах; остальные монеты — списком ниже.
Статистика ботаИтоги по реальным сделкам: покупки, продажи, потрачено, получено, заработано, прибыль «на бумаге», средняя цена покупки.
Активные позицииМонеты, которые бот купил и ещё не продал. У каждой видна прибыль/убыток и кнопка «Продать».
Управление ботом MEXCСтатус подключения и срок ключа, главные кнопки (выставить сетку, автопродажа, звук, обновить, отменить все), счётчики и таблица открытых ордеров с кнопкой «Отменить».
История ордеровОрдера бота со статусами: создан, исполнен, отменён. Хранятся последние 5000 записей, более старые удаляются.
ЖурналЛента событий: «Покупка исполнилась…», ошибки, предупреждения. Красные строки — ошибки, зелёные — удачные действия.
✅
Каждая монета работает отдельно
Переключатель вверху меняет актив для всех блоков сразу: параметры, ордера, история, статистика. Для каждой монеты бот запоминает свои настройки, а следит за всеми монетами из списка одновременно — даже если на экране сейчас открыта только одна.

🧭 Первая сетка шаг за шагом

Как выставить свою первую сетку

1

Выбери монету

Нажми нужную монету в верхней панели (список берётся из файла tokens.txt: добавил строку — кнопка появилась, перезапуск не нужен).

2

Выбери настройки

Нажми один из готовых наборов в «Быстрых настройках» (для начала подойдёт «Сбалансированный») или заполни поля сам.

3

Обнови цену

Нажми ⟳ live — в поле «Стартовая цена» подставится текущая цена монеты. Первый уровень будет ниже неё на один шаг.

4

Задай сумму и тейк-профит

Сумма ордера — сколько USDT тратить на один уровень (минимум около 1.05). Тейк-профит — на сколько % выше цены покупки продавать.

5

Проверь расчёт

Посмотри «Статистику сетки» и таблицу уровней. Особенно «Всего вложено»: на балансе должно быть столько свободных USDT.

6

Выставь сетку

Нажми «Выставить сетку на биржу», прочитай окно подтверждения и нажми «Подтвердить». Прозвучит сигнал, а в таблице открытых ордеров появятся ордера.

🧪
Для первого раза возьми маленькую сумму
Начни с 5–10 USDT всего: например, сумма ордера 1.05 и 5 уровней. Убедись, что всё работает как ожидаешь, и только потом увеличивай.
Пример с цифрами (ETH)

Стартовая цена 2 700, шаг 3%, сумма ордера 1.05 USDT, тейк-профит 5%. Бот получит такие первые уровни:

УровеньПросадкаЦена покупкиМонетСуммаЦена продажи (TP)
1−3.00%2 619.000.00040≈ $1.04≈ 2 749.95
2−5.91%2 540.430.00041≈ $1.04≈ 2 667.45
3−8.73%2 464.220.00042≈ $1.03≈ 2 587.43
  • Шаг считается от предыдущего уровня, а не от стартовой цены. Поэтому просадка копится чуть медленнее, чем «3%, 6%, 9%».
  • Монет покупается столько, сколько помещается в сумму ордера. Бирже нужны круглые значения, поэтому сумма в $ получается чуть меньше 1.05.
  • Каждый цикл на уровне 1 принесёт примерно 0.05 USDT (5% от суммы), минус комиссия биржи. Звучит скромно, но уровней много, а циклов может быть много.
Сколько получится уровней
Уровней = Диапазон ÷ Шаг (не больше 60) Диапазон 80%, шаг 5% → 16 уровней Диапазон 50%, шаг 10% → 5 уровней Диапазон 120%, шаг 2.5% → 48 уровней
  • Минимальный шаг и минимальный диапазон — 0.01%.
  • За один раз бот выставляет не больше 60 уровней. Если Диапазон ÷ Шаг получается больше, сетка обрезается, а под числом «Ордеров» в «Статистике сетки» появляется пометка, до какой просадки она реально дотягивается.
  • «Диапазон» — это не глубина падения цены. Из-за того, что шаг считается от предыдущего уровня, последний уровень получается заметно выше, чем «−Диапазон%». Точную просадку последнего уровня смотри в таблице уровней.
  • Стартовую цену меньше 0.000000001 бот не принимает (так что дешёвые монеты вроде PEPE или SHIB работают): подставится предыдущая нормальная цена или текущая рыночная.
Что проверяет бот перед выставлением
  • Показывает окно подтверждения с краткой сводкой сетки — ты видишь, что именно уйдёт на биржу.
  • Предупреждает, если часть уровней стоит выше текущей цены (биржа такие покупки отклонит) или глубже −97% от рынка (скорее всего, опечатка).
  • Не даёт отправить одну и ту же сетку дважды подряд (в течение 90 секунд) — защита от двойного клика.
  • Если какие-то уровни не прошли, показывает их номера и причину; остальные уровни выставляются.

Бот проверяет свои ордера каждые 3 секунды (параметр WATCH_INTERVAL) и работает одновременно для всех монет из списка. Каждый уровень в любой момент держит один открытый ордер: либо ещё не сработавшую покупку, либо (после покупки) продажу.

  • Цена продажи. Тейк-профит считается от реальной цены исполнения покупки. Если лимитная цена была 2575.35, а купилось по 2574.94, продажа ставится от 2574.94.
  • Цена новой покупки. Возврат на уровень идёт по цене самого уровня сетки.
  • Если продажу выставить не удалось. Бот пробует до 5 раз — по одной попытке на каждую проверку (по умолчанию раз в 3 секунды). Если не вышло — монеты остаются в «Активных позициях» с кнопкой «Продать», а в журнале появляется ошибка. Купленные монеты не теряются.
  • Если новую покупку выставить не удалось. Продажа уже прошла, поэтому цикл засчитывается в статистику, а в журнале появляется сообщение об ошибке.
  • Автопродажа выключена. Бот только покупает, продажу после покупки не ставит (подробнее в разделе «Кнопки и настройки»).
Что бот делает, если ордер «пропал» с биржи

Ордер может исчезнуть из списка открытых по разным причинам: он исполнился, ты отменил его вручную, биржа ответила с задержкой. Бот не паникует, а разбирается по шагам:

Ордер исполненФиксирует сделку и выставляет встречный ордер.

ℹ️
Запись «Отменён» в истории — это нормально
История показывает всю жизнь ордера: создан → исполнен / отменён / частично. Запись «Отменён» означает, что бот заметил отмену (твою или биржи) и аккуратно закрыл ордер у себя. Ошибки здесь нет.

Как работает «Отменить все ордера»
  • Что отменяется. Все открытые ордера бота по выбранной монете: и покупки из сетки, и продажи по тейк-профиту. Ордера, которые ты поставил на бирже вручную, не трогаются. Если открытых ордеров нет, кнопка неактивна.
  • Подтверждение. Перед отменой появляется окно со списком всех ордеров (сторона, цена, количество, время). Пока не нажмёшь «Подтвердить», ничего не произойдёт.
  • Отмена идёт по одному, с короткой паузой. Между отменами 0,25 секунды (параметр ORDER_MIN_INTERVAL). У MEXC создание и отмена ордеров делят один лимит запросов, и пауза не даёт его превысить. Из-за этого 60 ордеров отменяются примерно 20–25 секунд. Кнопка в это время показывает «⏳ Отмена…», страница не зависает, ответ ждётся до 90 секунд.
  • Частично исполненные ордера. После отмены бот проверяет, успела ли биржа исполнить часть ордера. Такой ордер остаётся под наблюдением, чтобы исполненная часть обработалась как обычно (поставилась продажа или повторная покупка). Остальные снимаются с наблюдения и записываются в журнал как отменённые.
  • Результат. Приходит сообщение «Успешно отменено N ордеров». Если часть не отменилась, отдельно показывается красное сообщение: число ошибок и причина для первых трёх ордеров. Обычно достаточно нажать кнопку ещё раз: уже отменённые ордера повторно не затрагиваются.
  • Лимит. Не больше 10 нажатий в минуту. Если нажать чаще, сервер ответит ошибкой о превышении частоты, подожди минуту.
  • Что остаётся на счёте. Отмена покупок освобождает USDT. Отмена продаж не продаёт монеты: они остаются на балансе без тейк-профита, пока ты не выставишь новую сетку или не продашь их вручную.

Кнопка «Продать» в активных позициях

Появляется у позиции, по которой сейчас нет ордера на продажу: например, автопродажа была выключена, ты отменил продажу или бот не смог её выставить.

  • Ставит новый ордер на продажу этих монет.
  • Цена продажи. Если процент в поле «Тейк-профит» такой же, как при покупке, берётся прежняя цена TP этой позиции. Если процент другой — цена пересчитывается: цена покупки × (1 + процент ÷ 100).
  • После продажи этой кнопкой бот не покупает заново на этом уровне: цикл закончен, позиция закрыта.
  • Пока запрос идёт, кнопка занята. Двойной клик ордер не удвоит.
⚙️
Что будет, если выключить автопродажу
Бот продолжит ставить покупки по сетке, но после исполнения не будет выставлять продажу. Купленные монеты останутся на балансе и появятся в «Активных позициях» с кнопкой «Продать» — закрыть их можно вручную в любой момент.

Когда это полезно: если хочешь просто накапливать монету; хочешь сам выбирать моменты продажи; рынок сильно растёт, и ты готов держать монеты дольше.

Всплывающие сообщения
  • Появляются при каждом событии и исчезают сами через 10–20 секунд. На экране одновременно не больше шести.
  • Всё, что произошло, остаётся в блоке «Журнал» (с возможностью выгрузить в Excel) — даже если ты не увидел сообщение.
  • Если пока тебя не было накопилось много событий, сообщениями показываются только последние пять, остальные записываются в журнал.
  • Кнопка «🔊 Звук» отключает только звук, а не сообщения.
«Звук заблокирован браузером. Кликните один раз в любом месте страницы»
  • Почему. Браузеры не разрешают странице играть звук, пока ты не кликнул или не нажал клавишу на ней. Это правило браузера, а не ошибка бота. После каждой перезагрузки страницы (Ctrl+F5) оно действует заново.
  • Когда появляется. Один раз после загрузки, если первое же сообщение со звуком пришло до твоего клика. Например, это может быть красное сообщение «Нет связи с сервером бота», если страницу открыли, а бот ещё запускается.
  • Что делать. Кликни один раз в любом месте страницы. В журнале появится строка «🔊 Звук включён», и дальше звуки играют как обычно, до следующей перезагрузки страницы.
  • Как убрать совсем. Разреши звук для адреса бота в настройках браузера — пошаговая инструкция ниже.

Свои звуки

Звуки лежат в папке Data/sounds/ и называются buy.mp3, sell.mp3, placed.mp3, cancel.mp3, info.mp3, error.mp3. Чтобы поменять звук, замени файл на свой с тем же именем и нажми Ctrl+F5. Если файла нет, вместо него прозвучит простой писк.

🔇
Если звука нет
1. Кликни один раз по странице бота. Браузеры запрещают звук, пока на странице не было ни одного клика. Если звук заблокирован, бот сам покажет подсказку; после клика появится запись «Звук включён».
2. Проверь кнопку: должна быть «🔊 Звук», а не «🔇 Без звука». Проверь, что звук вкладки не отключён в браузере и в Windows.
3. Держи открытой одну вкладку с ботом. Если открыть две, звук будет играть в каждой.
4. Звук в фоне. Если страница не на виду (другая вкладка, свёрнутый браузер), Edge и Chrome могут «усыплять» вкладку. Добавь адрес 127.0.0.1 в исключения: в Edge это «Настройки → Система и производительность → Оптимизировать производительность → Никогда не переводить эти сайты в спящий режим», в Chrome — «Настройки → Производительность → Экономия памяти → Всегда оставлять эти сайты активными». Названия пунктов в разных версиях немного отличаются.
5. Компьютер не должен уходить в сон, а окно с ботом (чёрное) должно быть открыто.

⬇ Полная статистика

Страница с графиком твоих реальных сделок: зелёные точки — покупки, красные — продажи, линии показывают точки отсчёта.

  • Период: 1, 3, 6 или 12 месяцев (кнопки сверху).
  • Циклы: сколько завершено (покупка → продажа), реализованная прибыль, средний профит за цикл, лучший, медианный и худший цикл, доля уже закрытых позиций из всех («закрыто из всех», рядом win rate закрытых: он почти всегда 100%, потому что бот не продаёт в минус), среднее время цикла и частота (циклов в день).
  • Деньги: ROI на вложенный капитал (к обороту; к замороженным деньгам — во всплывающей подсказке), капитал в обороте (заморожено плюс закрытые циклы), комиссии за период и проекция на месяц при том же темпе. Частота и проекция считаются от реального срока работы бота, если он короче выбранного периода (под сводкой это написано).
  • Риск: сколько открытых позиций сейчас ниже цены покупки и каков их бумажный убыток («в минусе сейчас»), число открытых позиций и сколько в них заморожено, нереализованный результат, худшая открытая позиция. Если бумажный убыток больше нуля, под сводкой показано, за сколько циклов и дней он окупится при текущем темпе.
  • «Бот vs Buy & Hold»: сравнение с теми же покупками, если бы их не продавали, на те же деньги. Так сравнение честное: холд не получает выгоду от самой дешёвой цены периода.

⬇ Бэктест сетки

Калькулятор для проб: подставь шаг, диапазон и тейк-профит и посмотри, как такая сетка вела бы себя на прошлых ценах. Реальные ордера не выставляются — это безопасная тренировка перед настоящим запуском.

  • Цены берутся с публичного API Binance. Период на выбор: 1, 3, 6 или 12 месяцев (для них используются свечи 1 час, 4 часа, 8 часов и 1 день).
  • Комиссия биржи учитывается: 0.1% с каждой стороны сделки. У твоего аккаунта на MEXC она может быть другой, поэтому прибыль на странице приблизительная.

🛡️ Безопасность, лимиты и сбои

Что будет, если пропадёт свет или интернет, и как бот обращается с ордерами

✅
Короткий ответ: ты ничего не потеряешь
Твои ордера физически лежат на серверах биржи MEXC. Если компьютер выключится или пропадёт интернет, ордера продолжат ждать на бирже и исполнятся, когда цена до них дойдёт. Бот в это время просто не будет ставить встречные ордера — он сделает это, как только запустится.
Что делает бот при сбоях
  • Безопасное сохранение. Своё состояние бот записывает сначала во временный файл и только потом подменяет им основной Data/autosell.json. Если свет выключится прямо во время записи, основной файл не пострадает. Раз в час бот делает копию в папку backups/.
  • Сверка после запуска. При старте бот сравнивает свой журнал с реальными ордерами на бирже. Если ордер исполнился, пока бот был выключен, он это заметит, учтёт сделку и выставит встречный ордер.
  • Спокойное ожидание связи. Если пропал интернет, бот не засыпает биржу запросами: он подождёт, запишет предупреждение в журнал и вернётся к работе, когда связь появится.
  • Расхождение времени. Если часы компьютера разошлись с часами биржи (например, после сна), бот сам пересчитывает поправку и повторяет запрос.
Ручные действия на бирже
ℹ️
Бот управляет только своими ордерами
Он отслеживает те ордера, которые выставил сам (или через кнопку «Продать» в своём интерфейсе). Чужие и ручные ордера на бирже он не трогает.

Если ты отменил или изменил ордер бота прямо на сайте MEXC, то при ближайшей проверке (через 3 секунды) бот увидит, что ордера нет, и уберёт его из наблюдения. Цикл этого уровня прервётся, остальные продолжат работать. Если отменена продажа по TP, позиция останется в «Активных позициях» с кнопкой «Продать» — нажми её, и бот выставит новую продажу (одна строка, без дублей).
⚠️
Лучше управлять через интерфейс бота
Пока бот работает, не отменяй и не меняй ордера этой пары на сайте биржи — это нарушает цикл «покупка → продажа». Для отмены используй «Отменить», для ручной продажи — «Продать» в интерфейсе бота: она проверит цену, закроет цикл и не вызовет повторную покупку.

Как считаются ордера
Один уровень сетки в любой момент держит ровно один открытый ордер: либо покупку, которая ещё не сработала, либо (после покупки) продажу. Продажа не добавляется к покупке — она встаёт на её место. Поэтому 40 уровней дают не больше 40 одновременных ордеров, сколько бы раз они ни исполнялись. После исполнения продажи бот по умолчанию сразу ставит новую покупку на этом же уровне — уровень продолжает работать, а не выбывает.
Встроенные защиты
  • Окно подтверждения перед выставлением сетки, отменой всех ордеров и отменой отдельного ордера.
  • Проверка цены каждого уровня: бот отклоняет покупку выше рынка и цену, которая слишком далека от рыночной (защита от опечатки, например лишнего нуля).
  • Повторная отправка той же сетки в течение 90 секунд отклоняется — защита от двойного клика и двух открытых вкладок.
  • Ограничение частоты действий: не больше 20 выставлений сетки, 10 отмен всех ордеров и 30 отмен отдельных ордеров в минуту.
  • Размер журнала событий и истории сделок ограничен, поэтому файлы не разрастаются бесконечно: по умолчанию хранятся последние 5000 записей истории ордеров, 10 000 сделок, 20 000 закрытых позиций и 1000 событий. Что старше, в статистике уже не учитывается (пределы можно поменять в .env).
  • Слежение за сроком API-ключа с цветным индикатором.
  • Аккуратная остановка по Ctrl+C: бот успевает сохранить состояние.
🔴
Что будет, если превысить лимиты биржи
Биржа ответит ошибкой «слишком много запросов» (код 429) и временно закроет доступ к API — обычно на несколько минут. При повторных нарушениях блокировка может быть дольше. Это блокировка доступа программы, а не потеря денег: средства на балансе остаются на месте, ордера на бирже тоже. Бот ставит ордера по очереди с паузами и обычно не подходит к этим границам.

  • Уже открыто слишком много ордеров (лимит биржи 500 на аккаунт) — отмени лишние или уменьши сетку.
  • Вышло сообщение про «слишком много запросов» — подожди минуту и повтори.
⚠️ После покупки нет продажи
  • Проверь, что включена «Автопродажа по TP: Вкл».
  • Подожди около 30 секунд: если продажу выставить не удалось, бот делает до 5 попыток.
  • Если не вышло, позиция появится в «Активных позициях» с кнопкой «Продать» — нажми её. Причина будет написана в «Журнале».
  • Посмотри в Data/autosell.json — исходный ордер должен числиться в разделе watch. Если что-то не так, перезапусти бота.
❓ В истории написано «Отменён» — бот сломался?
ℹ️
Всё в порядке
Это значит, что ордер отменила биржа или ты вручную. Бот заметил это, записал в историю и убрал ордер из наблюдения. Никаких «возвратов» он не делает и не зависает.
❓ Я вручную отменил или изменил ордер на бирже
ℹ️
Ничего страшного
При ближайшей проверке (через 3 секунды) бот увидит, что ордера нет, и уберёт его из наблюдения. Этот уровень прекратит цикл, остальные продолжат работать. Чтобы такого не было, отменяй ордера и продавай позиции кнопками в самом боте.
🔇 Нет звука

Кликни один раз по странице бота, проверь кнопку «🔊 Звук», держи открытой одну вкладку и добавь адрес бота в исключения «спящих вкладок». Подробный список — в разделе «Звуки и сообщения».

🔑 «API Key expired» или «Invalid API Key»
🔴
Решение
Скорее всего, срок действия ключа истёк. Создай новый на mexc.com/user/openapi, впиши MEXC_API_KEY, MEXC_SECRET_KEY и API_KEY_CREATED в .env и перезапусти бота. Если ключ новый, проверь, что в нём нет лишних пробелов и включены нужные права.
🔑 Срок ключа в боте не совпадает с биржей
  • Открой в браузере http://localhost:8000/api/ping и найди поле api_source.
  • "exchange" — срок взят прямо у MEXC, он должен совпадать с личным кабинетом с точностью до дня.
  • "env" — биржа не ответила, и срок посчитан по API_KEY_CREATED и API_KEY_DAYS из .env. Впиши точные дату и время создания ключа в кавычках, например "2026-08-18 17:29:29". Если указать только дату, дни могут отличаться от биржи на 1.
  • После правки .env перезапусти бота.
💱 «В ордерах» не равно сумме ордеров из истории
ℹ️
Это разное округление
«В ордерах» — сумма, которую биржа реально зарезервировала. Она округляет резерв по каждому ордеру отдельно (1.0496 USDT может стать 1.05), а «Сумма» в истории — это цена × количество, обрезанная до цента. Чем больше ордеров, тем больше разница, но ошибки нет: «Свободно» + «В ордерах» = «Всего».
💱 Цена продажи отличается на 0.01 от цены автоордера
  • Кнопка «Продать» берёт TP позиции, если процент в поле «Тейк-профит» не менялся. Если процент другой, цена пересчитывается от цены покупки.
  • TP считается от реальной цены исполнения покупки. Если процент у ордера не сохранился, он восстанавливается из цен, и возможна разница до 1 цента.
📁 Нет файла Data/autosell.json
  • Файл лежит в папке Data/ рядом с main.py и создаётся автоматически при первом запуске.
  • Если его нет после запуска, открой logs/backend.log и найди строки со словами «сохранить» или «CRITICAL». Проверь права на папку, антивирус и OneDrive.
  • Если сетка выставлялась, пока файла не было, бот эти ордера не отслеживает. Отмени их на бирже и выставь сетку заново.
🕐 Ошибка 700003 «Timestamp is outside of the recvWindow»
ℹ️
Время компьютера и биржи разошлось
Каждый запрос подписывается текущим временем, и биржа принимает его, только если часы почти совпадают. Расхождение бывает после сна компьютера или синхронизации времени Windows. Бот сам пересчитывает поправку и повторяет запрос, поэтому обычно это видно только в logs/backend.log. Если ошибка повторяется, включи синхронизацию времени Windows: Параметры → Время и язык → Дата и время → «Синхронизировать».
🌐 Данные не загружаются, везде «—», красное сообщение «Нет связи с сервером бота», индикатор «Ошибка подключения»
  • Проверь, что чёрное окно с ботом открыто и не показывает ошибок. Если закрыто — запусти start.bat заново.
  • Сообщение о потере связи показывается один раз на всю потерю, а не по штуке от каждого блока страницы. Когда бот снова ответит, придёт одно «Связь восстановлена», страницу перезагружать не нужно. Если ты только что перезапускал бота, подожди 10–20 секунд.
  • Открой интерфейс по адресу http://localhost:8000 и нажми Ctrl+F5.
  • Если окно с ботом открыто, но ошибки идут — смотри logs/backend.log.
⚠️ «MEXC не отвечает или отвечает ошибкой (503, таймаут или лимит запросов)», в журнале «service not available»
  • Это временный сбой самой биржи: сервер MEXC недоступен или перегружен. Ключи, интернет и бот в порядке.
  • Пока биржа молчит, бот не знает статусов ордеров, но ничего не отменяет и не снимает с наблюдения. Когда биржа вернётся, всё, что исполнилось за это время, обработается в ближайшем цикле.
  • Чтобы не засыпать экран, бот не проверяет каждый ордер отдельно, а показывает одно сообщение на монету (не чаще раза в 10 минут). Делать ничего не нужно.
  • Если такое повторяется часто, посмотри статус MEXC в их сообщениях или в соцсетях и проверь VPN или прокси.
🔄 Стартовая цена показывает странное значение или 0

Нажми «⟳ live» — подставится текущая цена. Значения меньше 0.000000001 бот не принимает и сам возвращает прежнюю нормальную цену.

🪙 Монеты нет в переключателе или кнопка не появилась
  • Проверь, что строка есть в tokens.txt и не начинается с # (это комментарий).
  • Файл должен лежать рядом с main.py или в папке Data/. Проверь, открывается ли он по адресу http://localhost:8000/tokens.txt.
  • Подожди до 30 секунд: страницы перечитывают файл раз в полминуты.
  • Проверь тикер на mexc.com (спот, пара к USDT). Монета, которой нет на бирже, на главной странице не показывается.
  • На странице графика не будет монет, которых нет на Binance: цены берутся оттуда.
🔬 Монета с очень маленькой ценой (PEPE, SHIB, BONK…)
ℹ️
Это нормально
У таких монет цена — доли цента, поэтому она показывается с большим числом знаков после запятой (например, $0.000003947), а монет в сетке получаются миллионы. Точность цены и количества бот берёт у биржи для каждой пары отдельно, так что в таблицах, окнах подтверждения и Excel цена не обрезается до двух знаков.
  • Сумма ордера по-прежнему в долларах (минимум около 1.05 USDT), а количество монет округляется вниз до точности биржи, поэтому «Сумма» в таблице уровней получается чуть меньше заданной.
  • «Средняя цена входа» и «Стартовая цена» тоже показываются с точностью рынка. Если видишь $0.00, нажми Ctrl+F5: страница, скорее всего, осталась старой версии.
  • Стартовая цена не может быть меньше 0.000000001.

✅ Чек-листы

Что проверить перед работой, во время неё и при остановке

Перед запуском
  • Установлен Python (с галочкой PATH)
  • Получены API-ключи на mexc.com/user/openapi
  • Включены права: Spot Reading, Spot Trading, Account Reading
  • Вывод средств (Withdraw) не включён
  • Ключ привязан к IP-адресу (по возможности)
  • Заполнен .env: ключи, API_KEY_CREATED, API_KEY_DAYS
  • На балансе есть свободные USDT
  • Первая проба — на маленькую сумму (5–10 USDT)
Во время работы
  • Окно с ботом открыто, компьютер не засыпает
  • Открыта одна вкладка с интерфейсом, звук включён
  • Открытых ордеров не больше 400
  • Срок ключа зелёный (иначе — пора менять)
  • В «Журнале» нет повторяющихся красных ошибок
  • Время от времени копируется Data/autosell.json

  • Остановить бота: Ctrl+C в чёрном окне
  • Решить, нужны ли ещё ордера на бирже (при необходимости — «Отменить все ордера» до остановки)
  • Сохранить копию Data/autosell.json
Нельзя делать
  • Включать право Withdraw на API-ключе
  • Показывать .env или выкладывать его в интернет
  • Закрывать окно бота резко (без Ctrl+C)
  • Удалять Data/autosell.json, пока на бирже висят ордера бота

  • Вручную отменять ордера бота на сайте биржи
